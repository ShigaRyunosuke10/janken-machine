# AIじゃんけんマシン改造ワークショップ 進行ガイド

子どもたち（中学生以上）が **AI（Claude）に日本語で指示を出して**、目の前のじゃんけんマシンに新機能を追加していくワークショップ。プログラミング経験は不要。「言葉で伝える → AIが作る → マシンが変わる」を体験してもらう。

## 当日の準備チェックリスト（主催者）

- [ ] じゃんけんマシンの電源を入れる（起動後1分でWi-Fi接続）
- [ ] PCで接続確認: `ssh janken@192.168.1.142 echo OK`（Git Bashで）
- [ ] Claude Codeをこのプロジェクト（`C:\dev\janken-machine`）で起動
- [ ] 復旧手順の確認: 何かあったら `bash scripts/restore.sh`
- [ ] 広報用のカメラ/スマホを用意（Before/Afterの動画が撮れると最高）

## 進行の流れ（例: 60〜90分）

1. **遊ぶ（10分）** — まず普通にじゃんけんで遊んでもらう。連勝システムと隠しコマンド（赤→黄→青→青→黄→赤）も見せると盛り上がる
2. **種明かし（10分）** — 中身はRaspberry Pi + Pythonで、AIに頼むと数十秒で書き換わることをデモ（下のお題メニューLv1を1つ実演）
3. **改造タイム（メイン）** — 一人ずつ順番に、AIへの指示を自分の言葉で言ってもらう。マシンに反映されたらみんなで確認
4. **記録** — できた機能ごとに写真/動画を撮り、[WORKSHOP_LOG.md](WORKSHOP_LOG.md) に記録（Claudeがやる）
5. **締め** — 採用する機能を決めてGitHubに保存。「きみたちの作った機能がこのマシンにずっと残る」と伝える

## お題メニュー（発案に詰まったとき用）

そのままAIに言えばOKの例。**自分の言葉で言い換えてもらうのが理想**。

### Lv1: ことば・色を変える
- 「タイトルの色をオレンジにして」
- 「勝ったときの『あなたのかち』を『さいきょう！』に変えて」
- 「負けたときにはげましの言葉を出して」

### Lv2: 数字・ルールを変える
- 「カウントダウンを5秒から3秒にして」
- 「隠しコマンドをぼくの決めた順番に変えて」
- 「3連勝したら『はんぱないって！』と出して」

### Lv3: あたらしい動きを作る
- 「勝ったときに画面がキラキラ光るようにして」
- 「CPUをちょっと弱くして（プレイヤーが勝ちやすく）」
- 「10連勝したらチャンピオン画面を出して」
- 「じゃんけんに『最強モード』を追加して」

### 発展: 自由発想
- 「こんなのできる?」をなんでもAIに聞いてみる。できるかどうかもAIが答える

## 約束ごと
