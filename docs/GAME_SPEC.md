# ゲーム仕様書

`src/main.py` に実装されている現行のゲームフローと演出の仕様。

## 状態遷移の全体像

```
[スタート待機] --スタートボタン--> [カウントダウン+手選択(5秒)]
     ↑                                    │
     │                    ┌───────────────┼───────────────┐
     │                 時間切れ        手を選択           │
     │                    │               ↓               │
     │                    │        [CPU選択・勝敗判定]     │
     │                    │               ↓               │
     │                    │        [対決画面 → 結果表示]   │
     │                    │        │        │        │
     │                    │       勝ち     負け    あいこ
     │                    │        ↓        │        ↓
     │                    │  [続行確認(5秒)] │  連勝中なら続行確認
     │                    │   │続行  │ﾀｲﾑｱｳﾄ │  連勝0なら待機へ
     │                    │   ↓      │      │
     └────────────────────┴──(リセット)──────┘
          続行時はカウントダウンへ戻る
```

## 各画面の仕様

### 1. スタート待機

- LEDマトリックス: 「じゃんけん / ゲーム / スタートを / おしてね」
- 最高記録が1以上あるときは「さいこう / きろく / n連勝」画面と4秒ごとに交互表示
- スタートボタンLED: 0.5秒間隔で点滅。他のボタンLEDは消灯
- スタートボタン押下（離した時）でゲーム開始

**隠し操作: 最高記録リセット**
- スタート待機中にスタートボタンを**10秒長押し**
- 2秒経過から「きろく / リセット / n」の赤いカウントダウンが表示される
- 10秒到達で記録を0にリセットし「きろくを / リセット / しました」を表示
- 途中で離せば通常のゲーム開始（スタッフ向けの運用操作）

**隠しコマンド（イースターエッグ）**:
- スタート待機中に 赤→黄→青→青→黄→赤 の順にボタンを押す
- 途中で間違えるか5秒間入力がないとシーケンスリセット
- 成立するとボタンLEDのレインボー演出 + 「じゃんけんマスター！ Made by Claude」表示（3秒）

### 2. カウントダウン + 手選択（統合・5秒）

- 表示: 「手を / えらんで」+ 残り秒数（5→1）
- 選択ボタン3つが0.3秒間隔で同期点滅
- 期間中いつでも選択可能: 赤=グー、黄=チョキ、青=パー
- 選択した瞬間にカウントダウンを打ち切り、選択ボタンのみ点灯
- 5秒経過で未選択なら「じかん / きれ」を2秒表示 → 連勝リセット → スタート待機へ

### 3. CPU選択・勝敗判定

- CPUは完全ランダム（rock / scissors / paper 等確率）
- 判定: rock > scissors > paper > rock

### 4. 結果表示

1. 対決画面（1.5秒）: 上段「あなた」+ プレイヤーの手、下段「わたし」+ CPUの手
2. 勝ちの場合はカラフルな紙吹雪演出（1.2秒、`show_win_sparkle`）
3. 勝敗表示:
   - 勝ち: 「あなたの / かち」+ 連勝中なら「n連勝中」
   - 負け: 「あなたの / まけ」
   - あいこ: 「あいこ」

**ボタンLED演出**:

| 結果 | 演出 |
|------|------|
| 勝ち | 全LED点滅 4回（0.15秒間隔） |
| 負け | スタートボタンLED点滅 3回（0.25秒間隔） |
| あいこ | 選択ボタン3つ同時点滅 3回（0.25秒間隔） |

### 5. 続行確認（勝ち・連勝中のあいこの後）

- 表示: 「(n連勝中) / つづきを / やる？」+ 残り秒数（5→1）
- スタートボタンLEDが0.3秒間隔で点滅
- 5秒以内にスタートボタン → 手選択へ（連勝継続）
- タイムアウト → 連勝リセット → スタート待機へ

## 連勝システム

- 勝つたびに `win_streak` +1、結果画面と続行確認画面に表示
- リセット条件: 負け / 手選択タイムアウト / 続行確認タイムアウト
- あいこは連勝数を変えない（連勝中は続行確認へ、連勝0なら直接スタート待機へ）

## 最高連勝記録

- `data/records.json` に保存（git管理外・電源を切っても残る）
- 自己ベスト更新のたびに「しんきろく / n連勝 / たっせい！」画面（2.5秒）
- 自動リセットなし。消すのは隠し操作（スタート10秒長押し）かファイル書き換えのみ
- 記録ファイルはLEDマトリックス初期化後の実行ユーザー（daemon）が書けるよう、
  `data/` を daemon 所有にしてある（`/home/janken` は 711）

## 画面レイアウトの規則

- 解像度64×64（32×64パネル2枚を縦連結、上下の画面境界は y=31/32）
- 全画面共通で上下端にシアンの装飾線（y=0, y=63）
- フォントは Noto Sans CJK JP 12px、`anchor='lt'` で描画
- 「チョキ」（3文字）のみ x=14、その他の手（2文字）は x=20 で中央揃え
- 行をパネル境界（y=31/32）にまたがせないこと
