# プロジェクト初期化チェックリスト

このチェックリストを使用して、新規プロジェクトの立ち上げが正しく完了したか確認してください。

---

## Phase 0: プロジェクト企画（ユーザー主導）

### プロジェクト概要

- [ ] プロジェクト名が決定している
- [ ] プロジェクトの目的が明確である
- [ ] ターゲットユーザーが定義されている
- [ ] 主要機能リストが作成されている

### 参考資料の準備

- [ ] `reference/` フォルダに要件定義書を配置した
- [ ] 必要に応じて以下の資料を配置した：
  - [ ] ワイヤーフレーム
  - [ ] ER図/データモデル
  - [ ] API仕様書
  - [ ] サンプルデータ
  - [ ] デザイン資料

### 技術スタックの選定

- [ ] フロントエンド技術を選定した
- [ ] バックエンド技術を選定した
- [ ] データベースを選定した
- [ ] 認証方式を決定した（必要に応じて）
- [ ] デプロイ先を決定した（必要に応じて）

---

## Phase 1: 初期設定（AI支援）

### 参考資料の確認

- [ ] `reference/` フォルダの内容を確認した
- [ ] 配置されている全ての資料を読み込んだ
- [ ] 要件が理解できる状態である

### CLAUDE.mdの更新

**必須項目**:
- [ ] `{{PROJECT_NAME}}` を実際のプロジェクト名に更新した
- [ ] `{{GITHUB_OWNER}}/{{GITHUB_REPO}}` を実際のリポジトリ名に更新した
- [ ] `{{FRONTEND_PORT}}` を設定した（例: 5173）
- [ ] `{{BACKEND_PORT}}` を設定した（例: 8000）
- [ ] `{{TEST_USER_EMAIL}}` を設定した
- [ ] `{{CURRENT_DATE}}` を現在の日付に更新した

**技術スタック**:
- [ ] フロントエンド欄に選定した技術を記載した
- [ ] バックエンド欄に選定した技術を記載した
- [ ] データベース欄に選定した技術を記載した

### .mcp.jsonの確認

- [ ] `.mcp.json` ファイルを確認した
- [ ] 必要なAPIキーが設定されているか確認した：
  - [ ] GitHub Personal Access Token
  - [ ] Netlify Personal Access Token（デプロイする場合）
  - [ ] その他の外部API認証情報
- [ ] 不足している設定がある場合、ユーザーに依頼した

### Serenaメモリの初期化

**必須ファイル**:
- [ ] `current_issues_and_priorities.md` を作成した
- [ ] `session_handover.md` を作成した

**フェーズ管理する場合**:
- [ ] `phase_progress.md` を作成した

**技術仕様がある場合**:
- [ ] `database_specifications.md` を作成した
- [ ] `api_specifications.md` を作成した

### 基本ドキュメントの作成

**必須**:
- [ ] `docs/SETUP.md` を作成した
- [ ] `docs/API.md` の雛形を作成した
- [ ] `docs/DATABASE.md` の雛形を作成した

**フェーズ管理する場合**:
- [ ] `docs/PHASES.md` を作成した

## Phase 2: 環境構築（AI支援）

### Dockerセットアップ

- [ ] `docker-compose.yml` を作成した
- [ ] フロントエンドサービスを定義した
- [ ] バックエンドサービスを定義した
- [ ] データベースサービスを定義した
- [ ] 必要なボリュームを定義した
- [ ] 環境変数を適切に設定した

### フロントエンド初期化

- [ ] `frontend/` ディレクトリにプロジェクトを作成した
- [ ] 選定した技術（React/Vue/Next.js等）で初期化した
- [ ] 必要な依存パッケージをインストールした
- [ ] `package.json` にスクリプトを設定した
- [ ] Dockerfile を作成した（Dockerを使用する場合）

### バックエンド初期化

- [ ] `backend/` ディレクトリにプロジェクトを作成した
- [ ] 選定した技術（FastAPI/Express等）で初期化した
- [ ] 必要な依存パッケージをインストールした
- [ ] 環境変数設定ファイルを作成した（.env.example等）
- [ ] Dockerfile を作成した（Dockerを使用する場合）

### データベース設定

- [ ] テーブル定義を作成した
- [ ] マイグレーションファイルを作成した（必要に応じて）
- [ ] 初期データのシードファイルを作成した（必要に応じて）
- [ ] `docs/DATABASE.md` にスキーマ情報を記載した

### 開発サーバー起動確認

- [ ] `docker-compose up -d` でサービスが起動する
- [ ] フロントエンドが `http://localhost:{{FRONTEND_PORT}}` でアクセスできる
- [ ] バックエンドが `http://localhost:{{BACKEND_PORT}}` でアクセスできる
- [ ] データベースに接続できる
- [ ] 各サービスのログにエラーがない
- [ ] フロントエンドからバックエンドへのAPI呼び出しができる

### ドキュメント更新

- [ ] `docs/SETUP.md` に環境構築手順を詳細に記載した
- [ ] `docs/DATABASE.md` にスキーマ定義を記載した
- [ ] `docs/API.md` に初期エンドポイントを記載した（作成した場合）

## 次のステップ

Phase 3（開発フェーズ）に移行したら：

1. **セッション開始時**: Serenaメモリから状態を読み込む
2. **機能開発**: feature ブランチで作業
3. **テスト**: e2e-tester サブエージェントでテスト
4. **PR作成**: code-reviewer サブエージェントでレビュー
5. **マージ**: docs-updater サブエージェントでドキュメント更新

詳細: [WORKFLOW.md](WORKFLOW.md)
